03 · Projects

Five builds, end to end.

Academic and self-directed projects from coursework — from classical ML to agentic pipelines, each built as a working application, not just a model. More on GitHub.

Language Detection System
React · Pydantic · Python · HuggingFace
  • Full-stack ML app classifying language from unstructured text using Naive Bayes & Logistic Regression, trained on HuggingFace's papluca dataset.
  • End-to-end pipeline from pickle-serialized model training to FastAPI production deployment — with auth, prediction history, and an admin analytics dashboard.
Sales KPI Analytics Dashboard
Python · SQL · Pandas · Flask · Seaborn
  • Real-time dashboard automating tracking of Revenue, Profit Margin, Sales Growth, AOV, and Retention — cutting manual reporting effort.
  • Applied K-Means, Logistic Regression, and Random Forest to segment customers and sharpen sales forecasting.
  • Interactive Seaborn/Matplotlib visualizations on a Flask backend for faster, data-driven decisions.
Marketing CrewAI Agent
CrewAI · Python · Gemini LLM
  • Multi-agent marketing automation system orchestrating specialized agents for research, scraping, and content generation.
  • Integrated SerperDev search, site scraping, and file I/O tools on a Gemini 2.0 Flash backend to autonomously plan and execute campaigns.
Shopping Assistant Agent
LangChain · SQL · Streamlit
  • Conversational assistant connecting an LLM agent to a SQL database for natural-language product search and recommendations.
  • Deployed via Streamlit for real-time, interactive querying of product data.
RAG Telecom Support Chatbot
LangGraph · LangChain · Streamlit
  • Retrieval-Augmented Generation chatbot for telecom support, using LangGraph to manage stateful, multi-turn conversations.
  • Retrieval chain grounds responses in domain-specific knowledge; deployed via Streamlit for real-time use.
